# Predy PRD – Product Requirements Document

## Objective
Build a standout, interactive, economically accountable AI agent swarm that wins multiple Synthesis bounties while feeling like a real startup product.

## Core Requirements (MUST-HAVE for MVP)
- Registration complete + ERC-8004 visible
- 4 visible agents with chat + Orchestrator
- VeriBond staking/slashing on every prediction
- Scoped testnet execution (Lido/Uniswap)
- Interactive human chat + @agent support
- Dashboard showing history, staking UI, proofs
- Full logs + agent.json + demo video

## Acceptance Criteria
- Dashboard shows live swarm discussion
- Prediction includes stake + confidence + resolution simulation
- Testnet tx + slashing/reward demo works
- Human can talk to any agent and get meaningful replies
- README + plan + demo video ready
- Submitted to Lido, Protocol Labs, Venice, Uniswap, Open Track

## Out of Scope for MVP
- Production mainnet + real money
- Advanced UI animations (keep simple but beautiful)

Success = Judges say “this feels like a real product with economic trust”.
